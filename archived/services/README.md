# Archived services

Archived September 8, 2026. This folder preserves the Services index, both service pages, their layout, and the service-card include at their original relative paths. Jekyll excludes `archived/`, and the services collection is disabled, so these files are not published.

To restore Services, move these files back to their matching paths at the repository root, enable the `services` collection with `output: true` and `permalink: /services/:path/` in `_config.yml`, and restore the Services link in `_includes/header.html` and the design reference navigation. The shared includes, styles, and images remain in the website source. Review enrollment details and policies before restoring publication.
